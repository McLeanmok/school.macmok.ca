Maybe this was a bit ambitious, but I wanted to create a record like diagram. I used the line extensively to produce the groves, and turntable anchor. On the backend, I used javascript varibls extensively to "tokenize" all major aspects of the drawing.

The aesthetic result I aimed for was something that was both nerdy, and nostalgic. I imagine a bubbly 50's record playing here. I would be very interested in learning how to drop an mp3 file in here, and maybe intergrate some basic animation? this could be the starting point for the final project.
